# Theory Lab

Static Astro site for Theory Lab, a member-led virtual lab within REQS Labs.

Preview address: `https://reqs-theory-lab.vercel.app`

Future public address: `https://theory.reqs.org`

Repository: `https://github.com/dsvt/reqs-theory-lab`

This site was generated from version `1.0.0` of the REQS member-lab template. Identity and public claims live in `src/data/`; shared layout and styling follow the template.

## Local work

```sh
pnpm install
pnpm dev
pnpm build
```

## Content rules

- Keep private source material out of the repository.
- Do not publish a role, affiliation, grant, partnership, metric, or output without a public source.
- Put uncertain details in source comments as `TODO: VERIFY`; keep them out of rendered pages.
- Past work by a member is not a lab output unless the lab actually produced it.
- Ask each person before adding them to the People page.

The generated `/reqs-lab.json` file gives the central REQS registry a small record to inspect. The hub remains curated through pull requests; it does not ingest member sites automatically.

The preview remains excluded from search indexing until the REQS subdomain and public claims are approved.

See `docs/onboarding.md` for the full review sequence.
